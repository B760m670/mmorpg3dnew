# Вертикальный срез №1 — Дворцовый ансамбль (эталон качества)

Первый участок, который доводим до **киношного финального качества** (планка
DMC5/RDR2). Он задаёт планку и пайплайн для всей территории: сюда вкладываем
руки, здесь «каждая деталь проработана». Остальная Гатчина пока — фоновый
массинг (`tools/build_city.py`), силуэт без крупного плана.

Принцип разделения труда (киношный, а не «всё вручную»):
- **Hero (вручную, по реальным референсам):** дворец, его башни и галереи,
  Коннетабль, ключевые павильоны. Лицо игры.
- **Фон (процедурно):** рядовая застройка слобод — массинг-коробки.

## Место (что это и что здесь было к 1894)

Большой Гатчинский дворец (1766–1781, Ринальди; перестройки Бренны) —
императорская резиденция. К 1894 (Александр III жил здесь постоянно) ансамбль
сложился окончательно: дворец лицом к **плацу**, за дворцом — партеры и террасы
к **Серебряному озеру**, дальше **Дворцовый парк** с озёрами и павильонами.

Реальная геометрия дворца (для hero-массинга, не «коробка»):
- центральный корпус (Корпус-каре) — трёхэтажный, протяжённый по дуге;
- две пятигранные башни над центром — **Часовая** и **Сигнальная**;
- две полукруглые галереи-циркумференции, охватывающие плац;
- боковые каре — **Кухонное** и **Арсенальное** (Гербовое);
- облицовка — местный камень (пудостский известняк, тёплый серо-охристый).

## Границы среза (координаты движка: X=восток, Z=−север, ноль=дворец)

- Центр: дворец **[19, 37]**.
- Радиус hero-детали: **300 м** (X∈[−281, 319], Z относительно −север).
- Контекст-кайма: ещё 200 м массинга-фона по периметру (мягкий переход).
- Рельеф/поверхность берём из уже готового `slice_palace.bin` (mpp=1 м,
  9 классов), центр [0, 400], радиус 950 — наш срез внутри него.

## Карта поверхности (классы slice_palace → трактовка)

| Класс | Где в срезе | Материал финального качества |
|------|-------------|------------------------------|
| плац (5) | перед дворцом | утрамбованный песок/гравий, колеи, лужи в низинах |
| газон (1) | партеры, Собственный сад | стриженый дёрн, ровный, тёмно-зелёный |
| аллея (4) | дорожки парка | светлый гравий, окантовка |
| мостовая (8) | подъезды, каре | булыжник (есть материал `cobble`) |
| роща/лес (2,3) | кромка парка | подстилка + отдельные деревья (hero-меши) |
| берег (7) | к Серебряному озеру | камыш, мокрый грунт, галька |
| вода (6) | Серебряное озеро | уже есть `water.gd` |
| луг (0) | вне ухоженной зоны | разнотравье |

## Инвентарь объектов среза

Hero (делаем поштучно, из реальной архитектуры):
1. **Дворец** — массинг по реальному плану (корпус + 2 башни + 2 галереи +
   Кухонное/Арсенальное каре), затем фасадные членения, окна, карнизы.
2. **Обелиск Коннетабль** [317, −372] — на площади (у кромки среза).
3. Ограда плаца, пандусы, парадный въезд.
4. Ключевые деревья партера (не трава — меши с LOD).

Фон (процедурно, уже есть): рядовая застройка за пределами hero-радиуса.

## Планка «готово» для среза (проверяемо)

- Дворец узнаётся по силуэту (башни, дуга галерей) — не параллелепипед.
- Под ногами на 300 м **нет двух одинаковых участков земли** — плац, газон,
  гравий, мостовая, берег читаются раздельно и по реальной карте.
- Материалы — многоканальный PBR (альбедо/шероховатость/нормаль/AO), не
  палитра-константа.
- Свет — уже настоящий (WorldClock), тени дворца ложатся на плац.
- Кадр «золотого часа» от плаца на дворец держит планку скриншота.

## Честные пробелы (список дефектов — по закону проекта)

- Высоты рядовых зданий **выведены** (данные их не несут) — фон, не истина.
- Крыши массинга плоские; скатные кровли — отдельный шаг.
- Точные членения фасада дворца требуют **референсов** (чертежи/фото) —
  без них массинг верен по объёму, но не по деталям.
- Эпоха: из данных Overture в срез пускаем только то, что существовало к 1894
  (сверка — при наполнении контентом).
- Финальный вид — только на устройстве (Metal); Linux даёт числа/структуру.

## Порядок работ по срезу

1. Спецификация (этот файл) — **сделано**.
2. Дворец-массинг по реальному плану (hero-геометрия вместо коробки).
3. Детальная карта поверхности среза на землю (плац/газон/гравий/мостовая).
4. Многоканальные материалы для поверхностей среза.
5. Коннетабль, ограда, парадный въезд, деревья партера.
6. Кадр золотого часа + список дефектов → итерация на устройстве.
