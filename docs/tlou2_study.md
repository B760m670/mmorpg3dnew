# Планка: The Last of Us Part II — полное исследование и карта применения

Цель — не любоваться, а **разобрать по слоям, ЧТО именно делает TLOU2 «настоящим»,
и решить по каждому слою: переносимо ли на наш конвейер** (форк Godot 4.5.2,
iPhone 16 Pro Max, Metal/MetalFX, Гатчина 1894) и как. Источники — доклады
Naughty Dog на SIGGRAPH 2020 и разборы (ссылки в конце).

## 0. Честная рамка переноса

TLOU2 — **PS4, 30 FPS, deferred-рендер, ОГРОМНЫЙ офлайн-бюджет запекания** и
студия художников. Наш стенд — телефон на 60–120 FPS, forward+, всё во многом
процедурно/данными. Значит переносим не реализацию, а **принципы**; тяжёлое
(GI, детализация) берём запеканием и мобильными приближениями. Ключевой вывод
сразу: **главный секрет TLOU2 — не полигоны, а СВЕТ и то, что размещение
никогда не случайно.** Оба принципа мы уже начали (физ-свет, поле жизни) — но
реализованы слабо.

---

## 1. СВЕТ — главный секрет (Doghramachi, «Lighting Technology of TLOU2»)

TLOU2 — пасмурный мир, поэтому **амбиентный свет решает всё**. Их запечённая
система амбиента:
- **Три носителя запечённого света**: light-map + вершинный свет + **пробы на
  сферических гармониках 3-го порядка** (SH-L2). Статичный фон — любой из трёх;
  динамические объекты переднего плана — только пробы.
- **Пробы**: интерполяция в 8 углах OOBB объекта → блоки 2×2×2 тексела в 3D-атласе
  → трилинейная выборка per-pixel. Дёшево и связно.
- **SSAO ненаправленный** для самозатенения.
- **Экранная трассировка конуса видимости** по буферу глубины как по height-field
  → мягкое амбиентное затенение (для пасмурного света критично); тем же кодом с
  узким конусом — тени солнца и локальных ламп.

**Наш статус**: SDFGI выключен (каскады дают полосу на горизонте — открытый мир),
держимся на SSAO+glow. GI фактически нет. Это — разрыв №1 с TLOU2.

**Действие для нас**:
1. **Запечённое GI вместо real-time**: Godot умеет LightmapGI (запекает
   лайтмапы + SH-пробы). Для статики Гатчины (дворец, земля-основа) — запекать;
   динамике (трава, персонаж) — ReflectionProbe/VoxelGI-пробы. Это прямой аналог
   их системы и снимает «плоский амбиент».
2. Небо у нас уже физическое (Рэлей/Ми) — оно и есть источник амбиента; надо
   довести его вклад через запечённое небо-освещение, а не ambient_light_energy.
3. Мягкие контактные тени — усилить SSAO + рассмотреть SSIL (Godot).

Приоритет: **высокий**. Свет даёт «кино» сильнее любой текстуры.

## 2. МАТЕРИАЛЫ — слоистые, реагирующие, мокрые

- **Слоистые шейдеры**, реагирующие на поворот объекта и связь слоёв: ржавчина
  рисуется только там, где нет мха (экономия выборок — дешевле шейдер).
- **Wet PBR**: дождь оставляет следы, поверхности реально мокнут (тёмный альбедо,
  ниже roughness, лужи в углублениях).
- **Фотограмметрия** как база материалов; detail-нормали нескольких частот;
  parallax/height для рельефа поверхности (не фейк-нормаль).
- Персонажам — render-target для крови/влаги поверх кожи.

**Наш статус**: только что подключили **реальные сканы (ambientCG CC0)** в шейдер
земли — это правильный слой 1. Но: без AO/height в шейдере, без wetness-отклика,
без detail-нормалей нескольких частот, гамма нормалей под вопросом.

**Действие**:
1. В шейдер земли добавить **AO + height (parallax)** из реальных карт (они уже
   скачаны), detail-нормаль второй частоты.
2. **Wetness-слой**, управляемый нашим полем почвы (влагоёмкость/деформируемость
   уже посчитаны!): мокрая глина темнее и глянцевее, лужи в низинах.
3. Материалы фасадов/камня — брать сканами (Blender→Godot), не палитрой.

Приоритет: **высокий** (мы в этом слое, надо углубить, а не бросить).

---

## 3. РАСТИТЕЛЬНОСТЬ — геометрия, плотность, СМЫСЛ размещения

- Трава — **геометрия**, десятки итераций на баланс «густо укрыть игрока ↔ FPS».
- **Stealth-grass**: типы травы для присесть/ползти; volume-объёмы считают,
  насколько игрок скрыт (расстояние до врага + позиция).
- **Размещение НИКОГДА не случайно** — у каждой лозы, цветка, куста есть причина
  (нарратив/среда). Это прямая формулировка нашего **поля жизни**.
- Трава качается на ветру; деревья дают динамические тени.

**Наш статус**: трава — геометрия (MultiMesh-лезвия), посев из **поля жизни**
(влага/свет/почва — не случайно!). Это концептуально ровно путь TLOU2. Но
плотность была мизерной (только подняли), лезвия примитивны, ветер простой,
кустов/цветов/деревьев-мешей нет.

**Действие**:
1. Плотность у ног — как у TLOU2 (укрывает по пояс); LOD по дистанции (билборды
   вдали). Профилировать FPS на устройстве — их главная борьба была тут.
2. **Растения-меши** (луговые травы, кусты, липы аллей, камыш берега) из Blender,
   инстанс по полю жизни. Разные виды по land-cover — как их «причина размещения».
3. Ветер — когерентное поле (шум по миру), не пофазный сдвиг.
4. Позже — stealth-механика травы (если будет геймплей укрытия).

Приоритет: **высокий** (это «оживление», которого требует заказчик).

---

## 4. АТМОСФЕРА и ПОГОДА — froxel, объём, состояния

- **Froxel volumetric fog**: view-space воксельная сетка по фрустуму → корректная
  композиция тумана со сценой (god-rays, тени в тумане).
- Погода как система: объёмные облака + атмосферное рассеяние + туман с тенями +
  wet PBR + ветер на листве + time-of-day цветокор + **переходы состояний**.

**Наш статус**: физ-небо (Рэлей/Ми) есть, объёмный туман (god-rays) есть,
WorldClock даёт настоящее время/солнце. Облаков нет, дождя нет, смены погоды нет,
wetness нет.

**Действие** (заказчик: «погода/дождь/облака — позже, но всё реально»):
1. **Объёмные облака** (raymarch по слою, из влажности/давления — физично).
2. **Погодные состояния** из времени/сезона (WorldClock уже ведёт) → дождь →
   wetness земли (через поле почвы) → лужи → деформация мокрой глины.
3. Наш froxel-туман (у Godot есть volumetric fog) уже близок — довести god-rays.

Приоритет: **средний** (после света/земли/травы; но архитектурно закладывать).

---

## 5. ЭФФЕКТЫ — GPU-driven (Kovalovs, SIGGRAPH 2020)

- Частицы **на GPU**: спавн по информации о мире, крепление и симуляция прямо на
  геометрии, огромные числа без ручной расстановки.

**Наш статус**: нет системы эффектов.
**Действие**: далеко; когда дойдём — compute-частицы (наш форк даёт нативный
Metal/RD). Пыльца в золотом часе, брызги, дым — по полю жизни/погоде.
Приоритет: **низкий**.

---

## 6. ПЕРСОНАЖИ (Николай — далеко, но планка ясна)

TLOU2-уровень кожи/лица: подповерхностное рассеяние (screen-space SSS), карты
морщин по напряжению мышц, tension-карты, глаза с преломлением, ткань с
анизотропией и симуляцией, мех/волосы прядями, motion-matching анимация,
захват лица. **Это отдельная студия-масштаб.** Закладываем только конвейер
(Blender→glTF→Godot с SSS-материалом), человека — когда мир готов его принять.
Приоритет: **отложен** (по закону проекта — последним).

---

## 7. ДЕФОРМАЦИЯ — снег/грязь/следы

TLOU2/Uncharted: снег и грязь **деформируются под шагами** (imprint в render-target
→ смещение геометрии), снег оседает на объекты, дождь оставляет следы.

**Наш статус**: посчитали **поле деформируемости почвы** (мокро/твёрдо) — данные
есть, рантайм-деформации нет.
**Действие**: imprint-буфер (render-target вокруг игрока) + смещение земли в
вершинном шейдере, глубина следа ∝ deformability. Наш форк (нативный Metal RD)
это позволяет. Приоритет: **средний** (сильный «настоящий» эффект под ногами).

---

## 8. ПОСТ-ОБРАБОТКА и СГЛАЖИВАНИЕ

TLOU2: temporal AA, контактно-мягкие тени, экранное SSS, DOF, motion blur, зерно,
хроматика, тонемап, per-shot цветокор.

**Наш статус**: кино-оверлей (зерно/виньетка/хроматика/ACES) есть; MetalFX
temporal (наш форк) = временная реконструкция ~аналог TAA-выигрыша. DOF/motion
blur нет.
**Действие**: DOF (кино-глубина) + motion blur в Compositor; довести ACES.
Приоритет: **средний**.

---

## 9. СТРИМИНГ / LOD

TLOU2: модульная архитектура (собрано из кусков, экспортируется единым мешем),
агрессивный стриминг, LOD, меш-инстансинг.

**Наш статус**: клипмап-LOD земли есть; город — единый меш массинга; стриминга
контента нет.
**Действие**: LOD зданий/растительности (билборды-импостеры вдали), потоковая
подгрузка вокруг игрока. Приоритет: **средний-высокий** при росте контента.

## Итог: карта разрывов и порядок работ

| Слой | TLOU2 | Наш статус | Разрыв | Приоритет |
|------|-------|-----------|--------|-----------|
| Свет/GI | запечённое GI + SH-пробы + cone-AO | GI нет, плоский амбиент | **большой** | 1 |
| Материалы | слоистые, wet, фотоскан, parallax | реальные сканы (база) | средний | 2 |
| Растительность | геометрия, плотно, по смыслу | поле жизни + редкая трава | **большой** | 2 |
| Деформация | снег/грязь под ногами | поле данных есть | средний | 3 |
| Атмосфера/погода | froxel, облака, состояния | небо+туман есть | средний | 3 |
| Пост | TAA/DOF/motion/grade | оверлей + MetalFX | средний | 4 |
| Стриминг/LOD | модульно+стриминг | клипмап земли | средний | 4 |
| Эффекты | GPU-driven | нет | низкий | 5 |
| Персонаж | SSS/muscle/cloth/anim | нет | (отложен) | — |

**Порядок, вытекающий из планки TLOU2:**
1. **Свет**: запечённое GI (LightmapGI + пробы) — снять «плоский амбиент». Даёт
   больше «кино», чем что-либо.
2. **Земля+трава как единый живой слой**: углубить материал (AO/parallax/wetness
   из уже готовых полей почвы) + плотная трава-геометрия + растения-меши по полю
   жизни. Профилировать на устройстве.
3. **Деформация под ногами** (imprint) — из готового поля деформируемости.
4. Погода/облака/дождь → wetness (реально, из условий).
5. Пост (DOF/motion), LOD/стриминг.

Каждый слой сверяем **на устройстве** (единственная правда), не офлайн-картинкой.
