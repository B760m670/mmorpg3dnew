# Исследование студийных инструментов: кто в чём лучший и что можем запустить мы

Среда: облачный Linux-контейнер, headless (без GUI), сеть ограничена политикой
(доступны PyPI и raw.githubusercontent; заблокированы huggingface.co, sidefx.com,
polyhaven.com, makehumancommunity.org). Проверено запросами 2026-07-15.

## Индустриальные станки и их статус для нас

| Инструмент | В чём лучший | Платформа/лицензия | Можем запустить? | Наш эквивалент |
|---|---|---|---|---|
| **ZBrush** (Maxon) | Скульпт: миллионы полигонов, кисти, альфы пор. Стандарт DMC5/RDR2 | Windows/macOS, платный, только GUI | ❌ нет Linux и headless | Blender: Multires/Dyntopo/Remesh + **true displacement** (микрогеометрия рендерится в Cycles реальной) + процедурные карты вместо ручных кистей |
| **Maya** (Autodesk) | Риг/анимация, стандарт студий | Linux есть, платный, нужна лицензия | ❌ лицензии нет | Blender armature + автопроба осей + NLA (уже работает) |
| **Marvelous Designer / CLO** | Крой и симуляция одежды | Win/mac, платный, GUI | ❌ | **Blender cloth sim** — уже применяем: крой по сечениям → драпировка (складки получились физикой) |
| **Substance Painter/Designer** | PBR-текстуры, смарт-материалы | платный (Adobe) | ❌ | Процедурные карты numpy + запекание AO/POSITION в UV (наша скан-методика) |
| **MetaHuman Creator** (Epic) | Фотореал-головы конвейером | бесплатный, но облако+GUI+UE | ❌ headless нет | MPFB (антропометрия) + таргеты по фото + SSS |
| **Houdini** (SideFX) | Процедурность, есть headless `hython` | Apprentice бесплатный, но сайт закрыт политикой | ❌ не скачать | Процедурность пишем прямо в bpy/numpy |
| **XGen/Ornatrix** | Груминг волос | внутри Maya / платный | ❌ | **Particle Hair** Blender: пряди + физика укладки + Principled Hair BSDF (меланин) — уже работает |
| **TexturingXYZ** | Скан-карты кожи (поры/displacement) | платный магазин | ❌ | Анатомические зоны + многооктавные поры в displacement |
| **AI photo-to-3D** (TripoSR/Hunyuan3D) | Болванка из фото | открытые веса на HF | ❌ HF заблокирован | Таргеты MPFB по фотографиям (итеративно) |
| **Blender 5 (bpy)** | Единственный полный DCC с headless Python | свободный | ✅ РАБОТАЕТ | Наш главный станок: скульпт-модификаторы, ткань, волосы, Cycles path tracing |

## Вывод

ZBrush лучший в ручном скульпте, но его сила — руки художника за GUI, у нас
их нет по определению; заменяем НЕ кистями, а измеримыми процедурами
(антропометрия → зоны → displacement) с обратной связью рендер→сравнение.
Все остальные станки индустрии имеют работающие эквиваленты в Blender,
и ключевые уже проверены в деле: симуляция ткани (складки кителя), пряди
волос с физикой укладки, Random Walk SSS кожа, true displacement пор,
трёхзонные глаза, кино-свет. Cycles — path tracer того же класса, что
рендеры кино-VFX. Итог: конвейер кино-качества реализуем целиком в нашей
среде; узкое место — не инструменты, а количество итераций доводки.
