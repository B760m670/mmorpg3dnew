# МАСТЕР-ПЛАН: пересоздание игры с нуля (кино-уровень, инженерный подход)

Решение: старый контент (game/ мир, город, здания) — черновик, НЕ мигрируется
и НЕ переписывается. Всё создаётся заново новыми станками. Сохраняется
ФУНДАМЕНТ: форк движка (4.5.2 + Metal/MetalFX), кино-конвейер персонажа,
инженерные аудиты (face_audit и следующие), симуляция ткани, патч-очередь.

Правила всех фаз: (1) сначала кино-качество, оптимизация потом;
(2) каждая система — отдельный файл/модуль; (3) у каждой фазы — измеримый
аудит (числа, не «на глаз»); (4) самые сложные задачи не откладываются.

## Ф0. Движок (ИДЁТ СЕЙЧАС)
- 4.5.2-стенд в песочнице (компилируется), Metal-шаблоны в CI (собираются).
- НОВЫЙ проект game2/ на 4.5.2 с нуля: Forward+, нативный Metal, MetalFX
  в оси «частота кадров», кино-пост через Compositor (ACES, зерно, хроматика).
- Сложная задача фазы: собственный CompositorEffect-стек (compute GLSL).

## Ф1. Станки контента (расширение существующих)
- Всё рождается в Blender в кино-качестве (Cycles-эталон) → адаптер в игру
  (запекание карт, LOD, hair cards из прядей). Один скрипт = один ассет,
  воспроизводимо, с автопревью и аудитом.
- Библиотека PBR-материалов ЭПОХИ: кирпич/пудостский камень/штукатурка/
  дерево/кровельное железо/сукно/кожа — каждый материал со сканной
  структурой (worley/микрорельеф), эталон в Cycles.
- Сложная задача: материал-аудит (рендер шара/стены при 3 освещениях,
  гистограммные проверки альбедо/roughness против референсов).

## Ф2. Человек (ИДЁТ: стадия A0)
A0 голая анатомия (аудит пропорций числами) → A1 кожа (SSS, поры,
микрорельеф) → A2 сходство по фото (face_audit: рендер↔фото Николая II)
→ A3 волосы прядями → A4 одежда кроем+тканью → A5 риг/движение
(twist-кости, corrective shapes, походка по эталонам) → A6 организм
(docs/human_organism_systems.md: кровь/боль/раны) → адаптация в игру.
- Сложная задача: likeness-петля — минимизация расхождения 478 ландмарок.

## Ф3. Мир-фундамент: настоящая Гатчина 1894
Источник истины — исторические планы Гатчины и парков (не выдумка):
оцифровка плана города 1880-1890-х (улицы, кварталы, озёра Белое/Чёрное/
Серебряное, Приоратский парк) в векторные данные (data/gatchina/*.geojson).
Рельеф: горизонтали с исторических карт + гидрология (озёра диктуют
высоты берегов). Почвы/биомы по ландшафту парков.
- Сложная задача: топографическая согласованность (вода не течёт вверх,
  дороги с реальными уклонами ≤ исторических норм для конки/экипажей).
- Аудит: наложение сгенерированного мира на план (пиксельная разница).

## Ф4. Архитектура: каждое здание — кино-проект
Большой Гатчинский дворец (600-м фронт, каре, башни — по обмерам и
фотографиям), Приорат (землебит!), собор Св. Павла, Балтийский вокзал.
Настоящие фасады: русты, карнизы, наличники, оконные переплёты со
стеклом, водостоки; интерьеры ключевых пространств дворца (парадная
анфилада) для сцен внутри.
- Сложная задача: параметрический фасадный станок (окно/карниз/руст как
  и manufactured-элементы с реальными профилями, боолевы проёмы).
- Аудит: рендер фасада против исторической фотографии (совмещение).

## Ф5. Город: улицы и дома по плану
Парцелляция кварталов по плану; типология: каменные особняки, деревянные
дома с резьбой, лавки, заборы, дворы, сараи, колодцы, фонари, вывески
дореформенной орфографии. Брусчатка/грунтовки по классам улиц.
- Сложная задача: процедурная типология с ручными доминантами (не
  «одинаковые коробки» — вариативность крыш/окон/декора по правилам эпохи).

## Ф6. Природа кино-уровня
Породы деревьев (сосна/ель/берёза/липа парков) — ствол с корой
(displacement), ветвление L-системой, листва картами с прозрачностью;
подлесок, трава по биомам, вода с волнами Герстнера + отражения SSR,
погода (дождь/снег/туман) и время суток.
- Сложная задача: ветер согласованно на деревьях/траве/ткани.

## Ф7. Масштаб и стриминг
Чанки мира, HLOD (запечённые дальние представления), VT-lite для
террейна, пул инстансов; бюджет: стабильные 120 FPS на A18 Pro при
MetalFX Temporal.
- Сложная задача: бесшовная подгрузка без фризов (потоковая загрузка +
  прекомпиляция пайплайнов).

## Ф8. Жизнь
NPC на человеческой платформе Ф2 (одна система на всех), распорядки дня,
лошади/экипажи, организм-системы в бою и быту, медицина 1894.
- Сложная задача: толпа с индивидуальными телами без дубликатов лиц
  (параметрические вариации MPFB + общий атлас).

## Порядок
Ф0-Ф1-Ф2 параллельно (движок собирается, человек уже в работе).
Ф3 стартует сразу после Ф0 (новый проект) — данные плана города.
Ф4 дворец — первый архитектурный кино-проект. Далее Ф5→Ф6→Ф7→Ф8.
Старый game/ остаётся в репо как референс до готовности game2/, затем
удаляется.
