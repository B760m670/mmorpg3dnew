# Форк движка: архитектура кастомного рендера (Metal / 4K / большие сцены)

## Что у нас фактически есть (проверено)
- **Полные исходники Godot (MIT)** локально: 1.2 ГБ, наш рабочий редактор
  4.3 собран ИЗ НИХ (custom_build 77dcf97d8) — форк-способность доказана.
- Тулчейн: scons + gcc13/clang, сборка Linux-редактора работает в песочнице.
- **CI на macos-15** (build-ipa.yml) — там Xcode + Metal SDK: кастомные
  iOS-шаблоны движка собираем в CI (локально Metal не собрать — Linux).
- Апстрим доступен: `git ls-remote` видит ветки/теги до `4.5.2-stable`.

## Ключевой факт (меняет план в нашу пользу)
Апстрим УЖЕ содержит то, что мы хотели писать сами:
- **4.4**: нативный Metal RenderingDevice (без прослойки MoltenVK) +
  прекомпиляция пайплайнов (убирает фризы компиляции шейдеров).
- **4.4/4.5**: **MetalFX upscaling — spatial и temporal** (то самое
  «рендерим ниже, апскейлим до нативного 4K экрана», ~16% экономии GPU).
Инженерно верно: база форка = `4.5.2-stable`, а наш труд идёт в НАДСТРОЙКУ,
а не в переизобретение Metal-бэкенда.

## Слои рендера Godot 4 (куда что вживляется)
```
Game (GDScript)  →  RenderingServer
                    └─ RendererSceneRender: forward_plus / mobile   ← кино-эффекты (Compositor)
                       └─ RenderingDevice (RD)                      ← вычислительные шейдеры
                          └─ drivers/: metal | vulkan | d3d12       ← MetalFX (уже в 4.5)
```
- **Модули C++ (modules/)** — для новых типов/узлов (наш стриминг, VT-менеджер).
- **Правки в servers/rendering и drivers/** — для глубоких фич (истинный VT).
- **Compositor/CompositorEffect (API 4.3+)** — кино-пост на compute-шейдерах
  БЕЗ форка: плёночное зерно, полный ACES, хроматика, виньетка, глубина кино.

## Наш форк: патч-очередь (профессиональная схема)
Репо игры НЕ хранит 1.2 ГБ движка. Храним:
```
engine/UPSTREAM        — пин: тег 4.5.2-stable + hash
engine/patches/*.patch — НАШИ правки движка (нумерованные)
engine/fetch.sh        — клон пина + наложение патчей
engine/build_linux_editor.sh   — редактор для песочницы (dev/verify)
engine/build_ios_templates.sh  — шаблоны iOS (запускается в CI macos-15)
.github/workflows/engine-templates.yml — сборка шаблонов, артефакт → релиз
```
build-ipa.yml после готовности шаблонов переключается с официальных
шаблонов на НАШИ (артефакт релиза), GODOT_VERSION → 4.5.2.

## Этапы работ
- **Э1. База**: миграция проекта 4.3→4.5 (формат совместим; проверяем мир,
  шейдеры, автолоады в 4.5-редакторе, собранном в песочнице). Линукс-сборка
  4.5 = наш верификационный стенд.
- **Э2. Metal-нативно + MetalFX**: включаем в экспорте `rendering_device/driver=metal`,
  ось «Частота кадров» GraphicsProfile получает режимы масштабирования:
  MetalFX Spatial (дёшево) / Temporal (качественно) / без. 120 FPS при
  нативной плотности пикселей достигается рендером ~0.77x + MetalFX.
- **Э3. Кино-пост (Compositor)**: ACES full + плёночное зерно + хроматическая
  аберрация + виньетка + тонкая плёнка бликов. Пишется у нас в game/ (GLSL
  compute), движок не трогаем. Это «кино-шейдеры» для рантайма.
- **Э4. Большие сцены / стриминг**: мир режем на чанки (у нас уже данные-
  ориентированная генерация), ResourceLoader.load_threaded_request на входе
  в радиус, выгрузка за радиусом; пул мешей. При упоре в движок — модуль C++
  `WorldStreamer` (свой поток + приоритеты по фрустуму).
- **Э5. Virtual Texture**: сначала VT-lite для террейна (клипмапы у нас
  частично есть: детальный участок под игроком — расширяем до колец LOD).
  Истинный sparse-VT с feedback-проходом — патчи в
  `servers/rendering/renderer_rd/storage_rd/texture_storage` + драйверные
  sparse-текстуры Metal; отдельная ветка патчей, включается флагом.
- **Э6. Узкие места**: профилируем на устройстве (Xcode GPU capture в CI
  артефактах не снять — метрики через Performance monitors Godot + наш HUD).
  Кандидаты: тени 4 сплита (→ 2 на mobile-профиле), объёмный туман,
  трава (→ compute-инстансинг с фрустум-куллингом в модуле C++).

## Ограничение среды (честно)
Metal-код компилируется/исполняется только на Apple-железе: локально мы
собираем и гоняем Vulkan/Linux-редактор (функциональная верификация),
Metal-шаблоны собирает CI macos-15, исполняет — твой iPhone. Цикл:
патч → линукс-стенд → CI-шаблон → IPA → телефон.
