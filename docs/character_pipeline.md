# Конвейер персонажа уровня AAA — этапы

Как реально делают персонажей в DMC5 / RDR2: фотограмметрия актёра → скульпт
(ZBrush) → ретопология под анимацию → UV → скан-текстуры кожи → риг (скелет,
веса, twist-кости) → анимация → шейдинг в движке (SSS кожа, анизотропные волосы).
Важно: **мышцы и органы в рантайме таких игр НЕ симулируются** — форма мышц
запекается в модель, движение даёт скелет + веса + корректирующие формы.
Наш аналог каждой ступени — Blender/MPFB (параметрическая анатомия по реальным
обмерам) + процедурные скан-карты + Godot Forward+.

## Этапы (по порядку, не смешивать)

1. **Скелет** — есть (MakeHuman default rig: позвоночник, конечности, кисти).
   Доводка: пропорции под рост 1.70 м (Николай II), оси костей автопробой.
2. **Тело/«мышцы»** — форма тела: макро-параметры (пол/возраст/сложение)
   + таргеты торса. Мышцы = форма меша, не симуляция.
3. **Кожа** — скан-методика без скана: запекаем ПОЗИЦИИ поверхности в UV
   и красим по анатомическим зонам (подкожная краснота: щёки, нос, уши,
   суставы; синева бритой щетины; глазницы; губы) + AO + пятнистость
   (3 октавы) + карта roughness (T-зона, губы) + поры в normal map.
   В движке: SubSurface Scattering (Godot StandardMaterial3D).
4. **Голова/сходство** — таргеты лица по фотографиям (нос, скулы, уши,
   подбородок). Имя «Николай» модель получает только после сходства.
5. **Волосы/усы** — сейчас оболочки; цель — карточные волосы (hair cards).
6. **Одежда** — СШИТАЯ геометрия, не «раздутое тело»: ровные срезы (bisect),
   построенные воротник/манжеты/ремень, НАСТОЯЩИЕ сапоги (голенище+ступня,
   пальцы закрыты), фуражка по форме головы. Ткань: PBR сукна.
7. **Механика движения** — скелетные анимации (idle/walk/jump) с фазами
   бедро-колено-стопа, противофазный мах рук, пружина корпуса. Дальше:
   naive twist-кости предплечий, corrective shapes на плечах.
8. **Шейдинг в движке** — SSS кожи, roughness-карты, при ходьбе — синхрон
   темпа шага со скоростью (уже есть в world.gd).

## Текущие известные дефекты (фикс в этапах 2-3-6)

- Кисти обёрнуты «перчатками» = фильтры белья/брюк без предела по X — кисти
  в A-позе попадают в их диапазон высот. Фикс: ограничение |x|.
- Зигзаг-края кителя/брюк = выборка по граням. Фикс: ровный bisect-срез.
- Сапог нет (пальцы наружу). Фикс: построенное голенище + ступня + подошва.
- Рост GLB 2.75 м. Фикс: нормировка до 1.70 перед экспортом.
- Кожа = плоский тон*AO. Фикс: этап 3.
- Баллонные плечи/грудь. Фикс: макро muscle/weight + слабее таргеты торса.
