# Человек как живой организм — поэтапная система (дизайн + движок)

Люди в игре — не «хитпоинты»: у них кровь, раны, боль, чувствительность,
физиология. Ниже — этапы, каждый строится на предыдущем; реализация в Godot
одним модулем на этап (scripts/human/*, по нашему правилу «каждая система —
свой файл»).

## Этап 1. Зонная анатомия (каркас всего)
Тело = зоны: голова, шея, грудь, живот, таз, плечи×2, предплечья×2, кисти×2,
бёдра×2, голени×2, ступни×2. У зоны: кости, сосуды (крупные/мелкие),
органы-модификаторы (мозг, сердце, лёгкие, печень, почки, желудок).
Попадание → зона → орган → эффекты. Модуль: `human/body_zones.gd`
(данные зон + маппинг на кости скелета GLB).

## Этап 2. Витальные контуры
- **Кровь**: объём ~5.0 л. Кровотечение внешнее (мл/с по типу раны и сосуду)
  и внутреннее (в полости). Пороги: <85% — слабость (скорость -15%),
  <70% — головокружение (шатание камеры), <60% — потеря сознания, <50% — смерть.
- **Дыхание**: лёгкие ×2; пневмоторакс → одышка, стамина падает вдвое.
- **Сознание**: перфузия мозга = f(объём крови, сердце, боль-шок).
Модуль: `human/vitals.gd` (тик 4 Гц, дешёвый).

## Этап 3. Боль и чувствительность
Ноцицепция по зонам (кисти/лицо чувствительнее бедра), суммарная боль →
шкала: дискомфорт → сильная боль (тремор прицела, стоны) → болевой шок
(падение давления → обморок). Адреналин: первые ~30 с после ранения боль
приглушена (реализм боя). Модуль: `human/pain.gd`.

## Этап 4. Раны и заживление
Типы: порез, колотая, огнестрельная, ушиб/перелом, ожог, обморожение.
У раны: зона, глубина, кровоток, загрязнение. Заживление стадиями
(гемостаз → воспаление → регенерация), при загрязнении — инфекция →
жар. Перелом ноги → хромота (скорость, анимация), руки — нет прицела/двуручного.
Модуль: `human/wounds.gd`.

## Этап 5. Энергия и терморегуляция
Голод/жажда/усталость/сон; температура тела 36.6 ± : холод Гатчины зимой,
мокрая одежда, у костра/в помещении теплее. Гипотермия → тремор → обморок.
Стамина = f(еда, вода, сон, кровь, раны). Модуль: `human/metabolism.gd`.

## Этап 6. Внешние проявления (то, что видит игрок)
- Кровь: декали на одежде у раны (растущее пятно), капли на земле по следу,
  лужа при лежании. Шейдер ткани: параметр namокания.
- Бледность лица при кровопотере (шейдер кожи: убавить подповерхностный
  красный), испарина при жаре.
- Анимации: хромота, прижатая рука, шатание, падение в обморок.
Модуль: `human/visuals.gd` + параметры в шейдерах кожи/ткани.

## Этап 7. Медицина эпохи (1894)
Бинт/жгут (остановка кровотечения), карболка/йод (антисептика), шина
(перелом), лауданум (боль, побочно — муть), врач/лазарет (шов, операция).
Никаких «аптечек +50HP». Модуль: `human/medicine.gd`.

## Порядок реализации
1→2 дают играбельный минимум (зоны, кровь, сознание). 3→4 — глубина боя.
5 — выживание/погружение. 6 — параллельно 2-4 (визуал продаёт систему).
7 — завершает петлю. NPC используют ту же систему (один код на всех людей).

## Связь с кино-персонажем
Кино-модель (стадии A/B) даёт слоты: карта кожи с параметром бледности,
зоны декалей крови на мундире, кости скелета ↔ зоны тела. Проектируем
модель СРАЗУ с этими каналами, чтобы не переделывать.
