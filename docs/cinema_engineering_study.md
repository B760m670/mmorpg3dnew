# Инженерные решения кино-графики: RDR2, Decima, GoT, TLOU2, UE5, RE Engine

Изучены первоисточники (доклады GDC/SIGGRAPH, официальные доки, разборы кадров)
— не чтобы копировать, а чтобы понять РЕШЕНИЯ. Формат: что делают они → что
берём мы (форк Godot 4.5.2 + Metal/MetalFX, iPhone A18 Pro, территория Гатчины
12–16 км на реальных данных, физический пешеход). Обновлено: июль 2026 (v2).

## Вывод №0 — главный
Кино-качество нигде не «один приём». Это **дисциплина данных реальности +
петли сверки**: Capcom шьёт настоящие костюмы и сканирует их; Rockstar
сканирует природу; Guerrilla строит мир правилами по картам данных. Никто не
рисует из головы. **Мы уже на этом пути**: реальный рельеф (SRTM), реальные
контуры города/воды (Overture), реальная астрономия и спектр Солнца — и
каждый слой сверяется числами.

## 1. RDR2 (SIGGRAPH 2019 + разборы кадра)
- Кадр: terrain depth prepass → G-buffer → свет → волюметрика → пост (TAA).
- Земля «помнит»: следы людей/лошадей/колёс пишутся в displacement-карту,
  рендер через Parallax Occlusion Mapping.
- Отражения: environment cubemap от камеры + split-sum IBL (мип-свёртки +
  BRDF LUT) — а не дорогие SSR.
- Атмосфера: физ.небо (Hillaire), фроксельный туман, raymarch-облака,
  ambient от неба.
**Мы**: схема неба/ambient совпала с нашей ✓; env-cubemap — для воды и окон;
displacement следов — в архитектуру слоя земли (снег/грязь 1894); объёмные
облака — Ф2.5.

## 2. Horizon / Decima (GDC 2017)
- **GPU-процедурное размещение**: растительность/камни не хранятся — compute
  сеет их вокруг игрока по картам плотности/правил (почва, уклон, влажность),
  детерминированный хеш — тот же мир без базы инстансов.
- **Стриминг мира**: тайлы кольцами вокруг игрока, жёсткие бюджеты памяти.
- Видимость: GPU-culling кластеров.
**Мы**: НАШИ МАСКИ УЖЕ ЕСТЬ — карта зон из реального землепользования и
высоты; трава/деревья сеять compute-хешем по зонам вокруг наблюдателя.
Стриминг кольцами — путь расширения за 12 км.

## 3. Ghost of Tsushima (GDC 2021)
- **Трава**: лезвия целиком на GPU (compute + indirect draw); мир в тайлах с
  текстурами высоты/материала/типа/кучности/ветра; каждое лезвие — кривая
  Безье со своей анимацией. Художник правит ПОЛЯ ПАРАМЕТРОВ, не объекты.
- **Стриминг**: весь остров без загрузок — дисциплина форматов и бюджетов.
**Мы**: чертёж травы Гатчины 1в1 (тайлы=наши зоны+высоты); на A18 — меньшие
радиусы, MetalFX добирает.

## 4. TLOU2 (SIGGRAPH 2020)
- **Свет**: запечённый ambient — лайтмапы, вершинный, SH-пробы 3-го порядка;
  интерполяция проб на 8 углов OBB (тексели 2×2×2 в 3D-атласе) → пиксельная
  трилинейка; пробы хранят ОККЛЮЗИЮ (сотни лучей с пробы) против протечек.
- **Волюметрика**: туман сэмплирует дерево проб (до 192 проб/фроксель),
  сетка до 5 млн фрокселей — резкие световые шахты.
- Motion matching; wrinkle maps; GPU-driven эффекты.
**Мы**: для города/дворца — ЗАПЕЧЁННЫЙ свет (LightmapGI + SH-пробы с
окклюзией). Наша практика подтвердила урок больно: SDFGI на открытом
мобильном мире = «пузырь» с яркостным швом (выключен коммитом 897f67b).

## 5. UE5 Nanite/Lumen (доки Epic)
- Nanite: меш → иерархические кластеры → стриминг и выбор детализации по
  видимости/расстоянию; software-raster мелких треугольников.
- Lumen: динамический GI (SDF-трейс + кэш поверхностей) — дорог; сами Epic:
  где свет статичен, баке дешевле.
**Мы**: принцип «детализация = функция расстояния» реализуем клипмап-кольцами
террейна вокруг наблюдателя (следующий шаг LOD) и кластерами застройки.
Lumen-класс GI на мобиле — не наш путь ✓ (совпало с TLOU2-выводом).

## 6. Virtual Texturing (Far Cry 4 AVT; UE RVT/SVT)
- Логическое текстурное пространство отвязано от VRAM, грузятся только
  видимые страницы; FC4: 10 тексель/см на мире 10×10 км.
- UE Runtime VT: композит материалов террейна в кэш-страницы на лету.
**Мы**: runtime-композит «зоны × детальные материалы» в кэш — среднесрочно;
полноценный sparse-VT на Metal — задача форка (бэклог движка).

## 7. Персонаж (RE Engine/DMC5, TLOU2, Hellblade 2)
- DMC5: настоящие костюмы → скан; лица 3Lateral; кожа SSS.
- TLOU2: анимация решает восприятие (motion matching), wrinkle maps.
- Hellblade 2: MetaHuman Animator (видео актёра → кривые лица).
**Мы**: цифровое ателье (крой по обмерам + симуляция) = их путь без сканера;
wrinkle maps через position-bake; MediaPipe (478 точек) как «капчер для
бедных». Анимации — приоритет не ниже кожи. Герой ≤120k треугольников.

## Сквозной чек-лист (наш порядок применения)
1. **Клипмап-LOD террейна** вокруг наблюдателя (детализация у ног + чистая
   даль) — следующий инженерный шаг земли.
2. **Трава/деревья по Decima/GoT**: compute-сев по нашим реальным зонам.
3. **Запечённый свет** для статики города/дворца (LightmapGI + SH-пробы),
   динамике — пробы. Realtime-GI на открытом мобильном мире — нет.
4. **Env-cubemap отражения** для воды/стёкол; позже — следы на земле
   (displacement) как у RDR2.
5. **Стриминг кольцами с бюджетами** — при выходе за 12 км.
6. Пост-стек уже верен: MetalFX temporal (=их TAA/апскейл), ACES, зерно.

## Аудит подхода (v3, июль 2026) — «гениально или можно лучше?»

Честная сверка нашего стека с индустрией кино-игр. Вывод сразу:
**архитектура верная и современная — отставание в АКТИВАХ и запечённом
свете, не в фундаменте.** Менять движок/путь не нужно.

### Что уже на уровне индустрии (оставляем)
- **Данные реальности как фундамент** (DEM, Overture-контуры, астрономия,
  спектр Солнца) — дисциплина Rockstar/Guerrilla (сканы/ГИС), а не
  «рисование из головы». Ни одна студия не делает иначе.
- **Клипмап-LOD террейна** — стандарт открытых миров (Far Cry, Halo Wars,
  UE-ландшафт); «детализация = функция расстояния» (принцип Nanite).
- **Детерминированный посев по картам правил** (трава/дороги выжигаются в
  зоны) — ровно Decima. Тот же мир при каждом входе, без базы инстансов.
- **MetalFX temporal + ACES + зерно** — аналог TAAU/DLSS-конвейеров.
- **Физический наблюдатель** (капсула, гравитация, heightmap-коллизия
  = видимая поверхность) — база иммерсии RDR2-класса.
- **Стенд с числовой сверкой (STATE)** — аналог студийных капчур-тестов.
- **Свой форк движка** — правильный выбор: UE5 (Nanite/Lumen) несовместим
  с путём «неподписанный IPA + LiveContainer + mobile Metal», а форк уже
  доказан на устройстве (60 FPS).

### Где мы НЕ на уровне (план подъёма, по важности кадра)
1. **Материалы поверхности**: сейчас заливки+шум, у студий — сканированные
   PBR-сеты (albedo/normal/roughness/AO). Megascans закрыт лицензией Epic,
   CC0-библиотеки (ambientCG/PolyHaven) закрыты сетью среды → наш путь:
   **офлайн-синтез PBR-текстур своим инструментом** (numpy: булыжник,
   грунт/колея, луговая дернина, кора) — «скан без сканера», как Capcom
   шьёт костюмы: по референсам, с проверкой чисел (гистограммы albedo).
2. **Деревья**: лес — 26% территории, пока только тёмная краска зон.
   Индустрия: LOD-меши + **octahedral impostors** (билборды-атласы с углов).
   Путь: процедурные стволы/кроны (L-система) → запечь атласы офлайн.
3. **Запечённый свет города** (когда встанут кварталы): LightmapGI +
   SH-пробы с окклюзией (решение TLOU2). Realtime-GI на мобиле — нет.
4. **Вода**: зеркало без волн/берега → волны Герстнера у берега,
   env-cubemap отражения (RDR2), пена кромки.
5. **Кино-язык камеры**: motion blur/DoF в пост-стек (у нас только
   зерно/виньетка) — дешёвые и дают «плёнку».
6. **Персонаж**: конвейер (Blender/MPFB2, мимика) был построен и ждёт,
   пока мир готов его принять — по закону проекта.

### Художественное зрение (работаю один — держу планку сам)
- Каждый слой сверяется не только числами, но и **референсом кадра**:
  северное лето, золотой час над лугом, пыльное шоссе, свинцовая вода.
- Палитра эпохи: грунт/макадам/булыжник, латунь/керосин вечером, никакой
  современной графики цвета.
- Композиция дали уже физическая (воздушная перспектива, туман низин) —
  дальше она должна работать НА кадр: слои силуэтов (парк→шпили→даль).
