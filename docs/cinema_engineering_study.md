# Инженерные решения кино-графики: RDR2, DMC5/RE Engine, TLOU2, GoW, Decima, UE5

Изучены первоисточники (доклады студий GDC/SIGGRAPH, разборы кадров) — не чтобы
копировать, а чтобы понять РЕШЕНИЯ. По каждой области: что делают они → что
берём мы (Godot 4.5-форк + Metal/MetalFX + A18 Pro + Blender-станки).

## Вывод №0 — главный
Кино-качество нигде не является «одним приёмом». Это **дисциплина данных
реальности + петли сверки**: Capcom для DMC5 ШЬЁТ НАСТОЯЩИЕ КОСТЮМЫ, надевает
на актёров и сканирует (одежда сшита в Лондоне, сканы в Сербии; лица — 3Lateral);
Ninja Theory снимает фотограмметрию Исландии и спутниковые данные; Rockstar
сканирует природу. Никто не «рисует из головы».
**Для нас** (сканеров нет): источник правды = параметрическая антропометрия
(MPFB — оцифрованные обмеры), исторические планы/фото города, ландмарк-петля
(face_audit 478 точек), материалы с worley/скан-структурой. Уже начали — верное
направление, усиливаем.

## Свет (важнее геометрии)
- GoW: объёмная сетка непрямого света (volume texture GI), GPU-запекание для
  быстрых итераций художников; bent normals + ambient specular occlusion.
- RDR2: физическая атмосфера (Hillaire) + фроксельный объёмный туман +
  raymarch облака; сетка GI-проб; tile-based deferred.
- UE5 Lumen: SDF-трейсинг + screen-space, аппаратный RT опционально.
**Мы**: мир по геометрии статичен → ЗАПЕКАЕМ GI (lightmaps + probes) для
города/дворца, динамика — пробы; физическое небо уже своё (Rayleigh/Mie);
объёмный туман Godot — тот же froxel-подход, что у RDR2 (включён в «Ультра»).
Bent normals запекаем в наших Blender-станках. Lumen-класс GI на мобиле не
тянуть — не наш путь, запечённое даёт кино-статику дешевле.

## Геометрия и масштаб
- UE5 Nanite (Karis, SIGGRAPH 2021, 155 стр.): меш → кластеры → DAG уровней
  детализации → стриминг по видимости; «работа только над тем, что видно».
- RDR2: постоянный стриминг мира, кадр начинается с создания/удаления ресурсов.
**Мы**: Nanite на Godot/мобиле нет — берём ПРИНЦИП: бюджет только на видимое.
Чанки мира + HLOD (запечённые дальние представления) + LOD-цепочки на всём +
occlusion culling. Герой 80-120k треугольников (подтверждено их бюджетами),
толпа — LOD-каскад.

## Персонаж
- RE Engine (DMC5): реальные костюмы → скан; лица 3Lateral; кожа — SSS.
- TLOU2: motion matching (база сотен движений, выбор по позе+намерению);
  wrinkle maps (морщины подключаются по позам лица); выстраданный вывод —
  качество анимации решает восприятие персонажа.
- Hellblade 2: MetaHuman Animator — видео актёра → кривые лица.
**Мы**:
- Одежда: наш путь уже совпал (крой по обмерам + симуляция ткани = их
  «сшить и надеть», только цифровое ателье). Усиливаем точность кроя эпохи.
- Wrinkle maps: реализуемо нашим position-bake станком — запечь карты морщин
  для ключевых выражений, блендить по позам (этап A5 лица).
- Motion matching: полный — оверкилл сейчас; фазовая походка → потом
  упрощённый выбор клипов по скорости/повороту (mm-lite). Вывод TLOU2
  принимаем: в анимацию вложиться не меньше, чем в кожу.
- Лицевой капчер: MediaPipe (видео → 478 ландмарок) может стать нашим
  «MetaHuman Animator для бедных» — кривые лица из видео. В бэклог A5.

## Мир и природа
- Decima (Horizon, GDC): GPU-размещение в рантайме — художник задаёт ГРАФ
  ПРАВИЛ (почва/уклон/влажность → что растёт), мир «выращивается» вокруг
  игрока, включая звуки и геймплейные объекты.
**Мы**: это точный чертёж нашей Ф6: правила биомов (у нас уже есть зачатки:
луг/лес/тропа) формализуем в data-driven граф правил: тип почвы + уклон +
близость воды → породы деревьев/подлесок/трава/камни. Размещение по правилам,
не руками. На GPU позже (compute), сначала CPU-генерация в чанки.

## Пост-обработка и «линза»
Все: filmic/ACES тонемап, плёночное зерно, хроматика, DOF, motion blur —
кадр смотрит «через объектив».
**Мы**: CompositorEffect-стек в Ф0 (compute GLSL): полный ACES, зерно,
CA, виньетка. Уже запланировано — подтверждено индустрией.

## Разрешение
Индустрия рендерит 50-70% и апскейлит (DLSS/FSR/чекерборд у консолей).
**Мы**: MetalFX Temporal (в форке 4.5) = тот же класс решения. Подтверждено.

## Оптимизация
- Tile-based deferred (RDR2), GPU-driven culling, async compute.
- Прекомпиляция пайплайнов (наш 4.4+ форк закрывает фризы шейдеров).
**Мы, mobile/TBDR**: Forward+ Годо на Apple TBDR уместен; главные рычаги —
меньше проходов глубины (у RDR2 их 3+ на даунсемплы: нам 1), теней сплитов
2-3 на мобиле, MultiMesh → позже compute-культинг травы.

## Что это меняет в наших планах (конкретно)
1. Свет мира: добавить в Ф3-Ф4 ЗАПЕКАНИЕ GI (lightmap/probes станок в Blender
   или Godot LightmapGI) — раньше в плане не было. Это самый большой рычаг
   «кино-света» на мобиле.
2. A5 лица: wrinkle maps через position-bake + MediaPipe-капчер из видео.
3. Ф6: граф правил размещения (Decima-подход) вместо «случайного разброса».
4. HLOD-станок в Ф7 (запечённые дальние чанки) — обязателен, не опция.
5. Анимации получают равный кожей приоритет (урок TLOU2).
6. Бюджеты героя/мира берём их цифрами: герой ≤120k, ткань/волосы LOD.
7. Ничего из этого не требует отхода от форка 4.5+Metal — наоборот,
   подтверждает выбранную базу.
