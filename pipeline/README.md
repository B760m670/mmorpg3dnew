# Конвейеры персонажа (Blender headless, bpy + MPFB2)

- `nicholas_film.py` — ОСНОВНОЙ, кино-уровень (см. docs/film_character_stations.md):
  анатомия → кожа SSS/поры/морщины → пряди волос (физика укладки) → глаза →
  кино-свет → Cycles-портрет. Флаги: `--quick` (итерации), `--naked` (стадия A0:
  голая анатомия, аудит пропорций, 3 ракурса).
- `nicholas_v2.py` — игровой GLB: крой одежды по обмерам + симуляция ткани,
  сапоги лофтом, скелет/анимации, экспорт uniform.glb/body.glb. Заморожен до
  готовности кино-версии (источник адаптации в game2/).
- `nicholas_glb.py` — устаревший (оболочки-«раздутое тело»), хранится как история.

Аудит лица: `python3 tools/face_audit.py <изображение>` — 478 ландмарок,
пропорции против канонов, асимметрия, разметка.

Запуск: `python3 pipeline/nicholas_film.py --quick --naked`
(нужны: pip bpy==5.x, MPFB2 в ~/.config/blender, данные makehuman в scratchpad).
