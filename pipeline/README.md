# Конвейер персонажей (Blender headless)

Каждый персонаж генерируется скриптом в облачном Blender (bpy + MPFB2/MakeHuman):
анатомия по макро-параметрам, морфы лица по историческим фотографиям,
запечённая кожа (Cycles AO), одежда, скелет со скиннингом и анимациями
(idle/walk/jump; оси суставов определяются автоматической пробой).

- `nicholas_glb.py` — Николай II: тело и мундир -> game/characters/nicholas/*.glb

Запуск: `python3.11 nicholas_glb.py` (требуется pip-пакет bpy и клоны mpfb2,
makehuman в рабочей директории — см. пути в начале скрипта).
