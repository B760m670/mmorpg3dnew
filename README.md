# Империя 1894 — Романовы. Открытый мир

3D-игра с открытым миром о России конца XIX века. Вы — цесаревич **Николай Александрович**, будущий император Николай II. Действие начинается **1 января 1894 года** на Дворцовой площади Санкт-Петербурга и идёт через **подлинные исторические события с точными датами** (по старому стилю).

## Что в игре

- **Дворцовая площадь 1894 года**, целиком сгенерированная кодом: Зимний дворец (в исторической терракотово-красной окраске той эпохи), Александровская колонна с ангелом, арка Главного штаба с колесницей Славы, газовые фонари, снег, смена дня и ночи.
- **Живой исторический календарь**: время идёт, и в свои реальные даты происходят события — смерть Александра III в Ливадии (20 октября 1894), принятие православия Аликс, венчание Николая и Александры (14 ноября 1894), речь о «бессмысленных мечтаниях», радио Попова, коронация (14 мая 1896), Ходынская катастрофа, золотой рубль Витте, первая перепись населения, I съезд РСДРП, Гаагская конференция…
- **События меняют мир**: Александр III умирает и исчезает из игры, императрица Мария Фёдоровна надевает траур, Аликс приезжает в Россию именно 10 октября 1894 года, ваш титул меняется с цесаревича на императора.
- **Исторические личности**, с которыми можно говорить: Александр III, Мария Фёдоровна, Александра Фёдоровна, Сергей Витте, Константин Победоносцев, лейб-гвардейцы. Реплики основаны на подлинных высказываниях.
- **Дневник событий** — внутриигровая летопись всего произошедшего.

## Технологии

- **РомановЪ-Движокъ (RomanovEngine)** — собственный игровой движок: ядро с подсистемами на фиксированном шаге симуляции (детерминизм независимо от FPS), система сохранений (автосейв каждый игровой день, кампания не теряется), живая погода с сезонами по историческому календарю (зимний снегопад с порывами ветра, летняя чистая брусчатка, осенние туманы), собственные GPU-шейдеры на Metal Shading Language: псевдоподповерхностное рассеивание кожи, сукно мундиров с бликом под углом, искрящийся иней на брусчатке под фонарями.
- **Swift + SceneKit/Metal** — рендер на нативном графическом стеке Apple. Ни одного стороннего ассета: весь мир, все персонажи, все текстуры (брусчатка, гранит, фасады, окна, снег, кожа, волосы, сукно) генерируются процедурно кодом при запуске.
- **Собственный скульптор персонажей** (`MeshBuilder` + `FaceBuilder` + `HumanBody`): головы — настоящие полигональные сетки с надбровными дугами, глазницами, скулами, носом и подбородком; тела — поверхности вращения с анатомическим профилем; скелет с коленями и локтями и процедурной походкой.
- **Файловая архитектура личностей**: каждая историческая фигура живёт в собственном файле `Sources/Personalities/<Имя>.swift` — внешность (антропометрия лица, телосложение, мундир/платье), биография и диалоги. Ничего не конфликтует и не теряется.
- **XcodeGen** — Xcode-проект генерируется из `project.yml`, в репозитории нет бинарных файлов.
- **GitHub Actions (macOS)** — сборка неподписанного IPA в облаке, без Mac и без Xcode на вашей стороне.

## Как установить на iPhone (без Mac)

1. Откройте вкладку **Actions** этого репозитория → последний успешный запуск **Build IPA**.
2. Внизу страницы, в разделе **Artifacts**, скачайте **RomanovEmpire-IPA** (внутри — `RomanovEmpire-unsigned.ipa`).
3. Установите IPA в **LiveContainer** (через iloader на Windows или напрямую импортом IPA в LiveContainer).
4. Запустите «Империя 1894» из LiveContainer. Игра работает в альбомной ориентации.

## Управление

- **Левый джойстик** — движение.
- **Правая половина экрана** — поворот камеры (свайп).
- **«Говорить»** — появляется рядом с персонажем; касание диалога листает реплики.
- **⏩** — ускорение времени ×8 (один игровой день ≈ 8 секунд при ×1).
- **📖 Дневникъ** — журнал исторических событий.

## Сборка вручную

```bash
brew install xcodegen
xcodegen generate
xcodebuild -project RomanovEmpire.xcodeproj -target RomanovEmpire \
  -configuration Release -sdk iphoneos \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY="" \
  CONFIGURATION_BUILD_DIR="$PWD/build" build
mkdir -p Payload && cp -R build/RomanovEmpire.app Payload/
zip -qry RomanovEmpire-unsigned.ipa Payload
```
