# Империя 1894

Игра кино-уровня об эпохе Николая II. Планка качества — DMC5/RDR2:
сначала кино, потом адаптация; никаких упрощений и ярлыков авансом.
Целевая платформа — iPhone (неподписанный IPA через LiveContainer),
до 120 FPS на ProMotion.

## Состояние (честно)

Проект в фазе пересоздания с нуля новыми станками. Что есть:

- **Движок**: форк Godot `4.5.2-stable` (пин + патч-очередь в `engine/`),
  нативный Metal + MetalFX upscaling; Linux-стенд для верификации,
  iOS-шаблоны собираются в CI (macos-15). Старый рантайм 4.3 — в `game/`.
- **Кино-конвейер человека** (`pipeline/nicholas_film.py`): анатомия MPFB,
  кожа Random Walk SSS + поры/морщины displacement, пряди волос с физикой
  укладки, трёхзонные глаза, кино-свет, Cycles. Стадия A0: голая анатомия
  с числовым аудитом. Это ещё НЕ «Николай» — имя надо заслужить сходством.
- **Инженерное зрение** (`tools/face_audit.py`): MediaPipe FaceMesh,
  478 ландмарок — аудит пропорций/асимметрии рендеров и фото, петля сходства.
- **Старый мир** (`game/`): черновик-референс, заморожен. Заменяется
  `game2/` по мастер-плану.

## Сборка

- IPA: GitHub Actions → **Build IPA** → артефакт → LiveContainer.
- Metal-шаблоны движка: workflow **Engine iOS Templates (Metal)**.
- Конвейер персонажа: `python3 pipeline/nicholas_film.py --quick [--naked]`
  (Blender 5 как bpy-модуль, MPFB2; см. `pipeline/README.md`).

## Рабочая модель

Направление и суд — за автором замысла; создание — за инженером. Ничего не
называется «Гатчиной» или «Николаем», пока не заслужило. Каждый этап имеет
измеримый аудит. Показ результата — вместе со списком его дефектов.
