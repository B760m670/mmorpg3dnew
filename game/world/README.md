# Мир Гатчины 1894

Единый источник истины — `gatchina/layout.json`. Из него генерируются рельеф,
карта и размещение зданий, поэтому мир и карта не расходятся.

## Конвейер (Blender 5 как bpy-модуль, без ПК/GUI)

```
layout.json ──┬─> tools/terrain_gen.py  -> gatchina/terrain.glb  (рельеф + вершинные веса материалов)
              │                             world/textures/*      (тайловые PBR: трава/земля/брусчатка)
              │                             gatchina/heights.json (высоты для посадки объектов)
              ├─> tools/buildings_gen.py -> world/buildings/*.glb (дворец, Приорат, собор, обелиск,
              │                             вокзал, типовые дома — каждое отдельным файлом)
              └─> tools/map_gen.py       -> gatchina/map.png      (обзорная карта: озёра, парки,
                                            дороги, здания, точка спавна)
```

Пересборка (пример):
```
python3 game/world/tools/terrain_gen.py  -- /path/to/repo
python3 game/world/tools/buildings_gen.py -- /path/to/repo
python3 game/world/tools/map_gen.py       -- /path/to/repo
```

## В игре (Godot)

`scripts/world.gd` собирает сцену: небо/солнце/туман, рельеф с шейдером
`shaders/terrain.gdshader` (смешивает три грунта по вершинному цвету и мировым
координатам), вода озёр (`shaders/water.gdshader`), деревья парков через
MultiMesh, здания из `layout.json` с коллизиями, персонаж-игрок (физика, джойстик,
бег, прыжок) и карта с маркером игрока.

## География (как в реальной Гатчине)

Дворец на холме над Серебряным озером → Дворцовый парк вокруг Белого озера →
Большой проспект через площадь Коннетабля к собору Св. Павла → Приоратский дворец
на берегу Чёрного озера → вокзал на юге. Местность равнинная (Ижорское плато);
горных районов здесь нет — они появятся в других локациях тем же конвейером.
