# Браузерная версия

Тот же срез Гатчины, что и в версии для телефона: земля и урез воды сняты
`tools/export_web_slice.py` теми же функциями, что читает игра (`terrain.height`,
`water_real.level_at`), а физика воды — тот же
`engine/modules/gatchina_sim/water_field.h`, собранный в WASM. Своё здесь только
рисование.

## Запустить

Нужен любой статический сервер — из-за модулей ES и `fetch` открывать
`index.html` файлом с диска нельзя.

```sh
cd web
python3 -m http.server 8099
```

и открыть <http://127.0.0.1:8099/>.

## Управление

Два режима, как в версии для телефона. Переключает кнопка внизу справа, а также
двойной тап и `Tab`.

**СВЕРХУ** — свободная камера над парком (порт `free_camera.gd`):
один палец тянуть — смотреть, два пальца — вести камеру («развёл = ближе»,
потянул — «схвати мир»), скорость пропорциональна высоте.
На клавиатуре: `WASD`, `Q`/`E` вниз-вверх.

**ПЕШЕХОД** — тело на земле (порт `walker.gd` и `water_physics.gd`):
ЛЕВАЯ половина экрана — стик движения (дальше увёл — быстрее, до бега),
ПРАВАЯ — взгляд. Настоящая гравитация; в воде — брод с пределом скорости из
уравнения сопротивления и плавание там, где на ногах остаётся меньше пятой
части веса. Шаги по мелководью гонят круги через тот же решатель, что и камень.
На клавиатуре: `WASD`, `Shift` бежать.

Короткое касание (клик) — бросить камень в воду.

Инверсий нет ни по одной оси ни в одном режиме — это правило проекта.

Ракурс можно задать адресом, не трогая код:

- `?view=shore` (по умолчанию) — у кромки, глаз человека
- `?view=near` — в двух шагах от воды, видно берег и толщу
- `?view=down` — с пригорка на всё озеро
- `?view=top` — сверху на весь срез
- `?eye=x,y,z&at=x,y,z` — произвольная точка и цель
- `?dbg=refl` — показать буфер отражения на весь экран
- `?dbg=1..5` — разбор шейдера воды по слагаемым:
  1 толща · 2 отражение×Френель · 3 Френель · 4 пена · 5 глубина
- `?hud=full` / `?hud=min` — полная телеметрия или одна строка

## Пересобрать данные и WASM

```sh
python3 tools/export_web_slice.py            # -> web/data/slice.bin (1028 КБ)
web/wasm/build.sh                            # нужен emscripten (em++)
npm install && cp node_modules/three/build/three.{module,core}.js vendor/
node build_single.mjs dist/gatchina.html     # всё в один файл (2 МБ)
```

Последняя сборка нужна, чтобы открыть игру С ТЕЛЕФОНА БЕЗ КОМПЬЮТЕРА: одна
страница, внутри которой и three.js, и WASM, и срез. Её можно положить куда
угодно и открыть по ссылке — локальный сервер для неё не нужен.

## Снять кадр без глаз

```sh
node shot.mjs /tmp/кадр.png 6000 view=near
```

Требует `npm install` (playwright) и Chromium.
